Translations

The repository contains localized installation and architecture documents. The English guides above are concise; translated pages are available in the GitHub docs directory, including Afrikaans, Arabic, Catalan, Simplified and Traditional Chinese, Croatian, Czech, Dutch, Farsi, French, Galician, German, Hebrew, Hungarian, Indonesian, Italian, Japanese, Korean, Latvian, Malay, Mongolian, Polish, Portuguese, Romanian, Russian, Spanish, Swedish, Slovenian, Tamil, Thai, Turkish, and Ukrainian.

Translations are maintained alongside the English source. If a localized page differs, follow the current English guide and report the discrepancy through GitHub Issues.
