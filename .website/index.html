Why Jarock

Practical tools, not a maze of instructions.

Everything in the repository is designed to be understandable, inspectable, and usable from any folder on a Windows machine. The bootstrap downloads the selected loader and pinned server-side files when you first launch.

Quick start

From empty folder to first launch.

You do not need to manually assemble a loader, libraries, or performance mods. Jarock downloads the selected runtime and verifies the pinned server files for you.

Open the complete English guide ↗
  1. 01
    Download and extract

    Put the repository in a writable folder. Spaces and ordinary deep paths are supported.

  2. 02
    Run start-server.bat

    Choose Fabric, or NeoForge if a required mod needs it. Configure parameters when prompted.

  3. 03
    Accept the EULA

    Set server/eula.txt to eula=true only after reading Minecraft's EULA.

  4. 04
    Test locally first

    Review the logs, add trusted players, then configure public networking manually if needed.
