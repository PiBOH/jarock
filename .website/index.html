Jarock Minecraft Server Toolkit

A beginner-friendly, loader-aware Windows bootstrap for a professional Minecraft Java 26.2 server.

Jarock installs and verifies a selected server loader, configures a safe local runtime, and provides documentation for Java/Bedrock cross-play. Fabric is the recommended first choice; NeoForge is the fallback when a required mod needs it.

Important notes

Before you start: Install a compatible 64-bit Java 25 runtime, run start-server.bat from the repository root, and read the generated server/eula.txt. Do not launch server/server.jar directly.
