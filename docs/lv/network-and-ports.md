# Tīkla, ugunsmūra un maršrutētāja rokasgrāmata

Instalējiet 64 bitu Java 25, palaidiet `start-server.bat` un pabeidziet `TODO.md` pirms portu atvēršanas. Piešķiriet fiksētu LAN IP, atveriet TCP `25565` (Java) un UDP `19132` (Bedrock) Windows ugunsmūrī, konfigurējiet portu pārsūtīšanu maršrutētājā vai izmantojiet UDP saderīgu tuneli, piemēram, playit.gg. Pārliecinieties, ka `online-mode=true` un `white-list=true` ir iespējoti un nekad nepubliskojiet `key.pem`. CGNAT gadījumā izmantojiet tuneli. Skatiet [kanonisko angļu rokasgrāmatu](../en/network-and-ports.md).

> Vienmēr izmantojiet `start-server.bat`; neveiciet dubultklikšķi uz `server.jar`.
