# Panduan pelayan Fabric

Pasang Java 25 64-bit, jalankan `start-server.bat` dan gunakan `parameter-manager.bat` untuk RAM serta GUI atau `nogui`. Baca `server/eula.txt`, terima EULA dan tetapkan `eula=true`; gunakan Fabric, Geyser-Fabric dan Floodgate-Fabric, buat sandaran, dan Jarock tidak mengubah router, firewall atau port forwarding.

Lihat panduan lengkap bahasa Inggeris: [../en/server-guide.md](../en/server-guide.md)
