# راهنمای سرور Fabric

Java 25 شصت‌وچهاربیتی را نصب کنید، `start-server.bat` را اجرا کنید و با `parameter-manager.bat` حافظه و GUI یا `nogui` را تنظیم کنید. `server/eula.txt` را بخوانید و بعد از پذیرش EULA مقدار `eula=true` را بگذارید. از Fabric، Geyser-Fabric و Floodgate-Fabric استفاده و backup تهیه کنید. Jarock روتر، firewall یا port forwarding را تغییر نمی‌دهد.

See the [canonical English installation guide](../en/server-guide.md) for the complete procedure. Keep commands, paths, keys and URLs unchanged.
