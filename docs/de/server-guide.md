# Fabric-Serverhandbuch

Installieren Sie 64-Bit-Java 25, starten Sie `start-server.bat` und verwenden Sie `parameter-manager.bat` für RAM sowie GUI oder `nogui`. Lesen Sie `server/eula.txt`, akzeptieren Sie die EULA und setzen Sie `eula=true`; verwenden Sie Fabric, Geyser-Fabric und Floodgate-Fabric und erstellen Sie Backups. Jarock ändert Router, Firewall und Portweiterleitung nicht.

Lesen Sie die vollständige englische Anleitung: [../en/server-guide.md](../en/server-guide.md)
