# Fabric 伺服器指南

安裝 64 位元 Java 25，執行 `start-server.bat`，使用 `parameter-manager.bat` 設定記憶體與 GUI 或 `nogui`。閱讀 `server/eula.txt`，接受 EULA 後才設為 `eula=true`。使用 Fabric、Geyser-Fabric、Floodgate-Fabric 並先備份。Jarock 不修改路由器、防火牆或 port forwarding。

See the [canonical English installation guide](../en/server-guide.md) for the complete procedure. Keep commands, paths, keys and URLs unchanged.
