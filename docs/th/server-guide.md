# คู่มือเซิร์ฟเวอร์ Fabric

ติดตั้ง Java 25 แบบ 64 บิต เรียกใช้ `start-server.bat` และใช้ `parameter-manager.bat` ตั้งค่า RAM กับ GUI หรือ `nogui` อ่าน `server/eula.txt` ยอมรับ EULA แล้วตั้ง `eula=true`; ใช้ Fabric, Geyser-Fabric และ Floodgate-Fabric ทำ backup และ Jarock ไม่แก้เราเตอร์ ไฟร์วอลล์ หรือ port forwarding

ดูคู่มือภาษาอังกฤษฉบับเต็ม: [../en/server-guide.md](../en/server-guide.md)
