# Fabric-serverguide

Installera 64-bitars Java 25, kör `start-server.bat` och använd `parameter-manager.bat` för RAM och GUI eller `nogui`. Läs `server/eula.txt`, godkänn EULA och sätt `eula=true`; använd Fabric, Geyser-Fabric och Floodgate-Fabric, skapa säkerhetskopior, och Jarock ändrar inte router, brandvägg eller port forwarding.

Se den fullständiga engelska guiden: [../en/server-guide.md](../en/server-guide.md)
