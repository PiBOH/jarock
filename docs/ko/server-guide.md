# Fabric 서버 안내서

64비트 Java 25를 설치하고 `start-server.bat`을 실행한 뒤 `parameter-manager.bat`으로 RAM과 GUI 또는 `nogui`를 설정합니다. `server/eula.txt`를 읽고 EULA에 동의하여 `eula=true`로 바꾸며 Fabric, Geyser-Fabric, Floodgate-Fabric을 사용하고 백업을 만드세요. Jarock은 라우터, 방화벽 또는 port forwarding을 변경하지 않습니다.

영어 전체 안내서를 참조하세요: [../en/server-guide.md](../en/server-guide.md)
