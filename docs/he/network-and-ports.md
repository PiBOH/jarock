# מדריך רשת, חומת אש ונתב

התקן Java 25 64-bit, הרץ `start-server.bat` והשלם את `TODO.md` לפני פתיחת פורטים. קבע IP LAN קבוע, פתח TCP `25565` (Java) ו-UDP `19132` (Bedrock) בחומת האש של Windows, קבע העברת פורטים בנתב או השתמש במנהרת UDP כמו playit.gg. וודא `online-mode=true` ו-`white-list=true` ולעולם אל תפרסם את `key.pem`. עבור CGNAT השתמש במנהרה. ראה [מדריך באנגלית](../en/network-and-ports.md).

> השתמש תמיד ב-`start-server.bat`; אל תלחץ פעמיים על `server.jar`.
