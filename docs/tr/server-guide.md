# Fabric sunucu kılavuzu

64 bit Java 25 kurun, `start-server.bat` çalıştırın ve RAM ile GUI veya `nogui` ayarlarını `parameter-manager.bat` üzerinden yapın. `server/eula.txt` dosyasını okuyun, EULA’yı kabul edip `eula=true` yapın; Fabric, Geyser-Fabric ve Floodgate-Fabric kullanın, yedek alın, Jarock router, firewall veya port forwarding değiştirmez.

Tam İngilizce kılavuza bakın: [../en/server-guide.md](../en/server-guide.md)
