# Guía do servidor Fabric

Instala Java 25 de 64 bits, executa `start-server.bat` e usa `parameter-manager.bat` para configurar RAM e GUI ou `nogui`. Le `server/eula.txt`, acepta a EULA e pon `eula=true`; usa Fabric, Geyser-Fabric e Floodgate-Fabric e fai copias. Jarock non modifica router, firewall nin port forwarding.

Consulta a guía completa en inglés: [../en/server-guide.md](../en/server-guide.md)
