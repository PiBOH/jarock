# Panduan server Fabric

Pasang Java 25 64-bit, jalankan `start-server.bat`, dan gunakan `parameter-manager.bat` untuk RAM serta GUI atau `nogui`. Baca `server/eula.txt`, terima EULA lalu tetapkan `eula=true`; gunakan Fabric, Geyser-Fabric dan Floodgate-Fabric, buat backup, dan Jarock tidak mengubah router, firewall atau port forwarding.

Baca panduan lengkap bahasa Inggris: [../en/server-guide.md](../en/server-guide.md)
